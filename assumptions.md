# Assumptions

This file records the assumptions made during the Tailwyndz project.

## Current Assumptions

1. The raw datasets will not be changed during the project.
2. All data cleaning is done on working copies.
3. District names are standardized before joining datasets.
4. Mixed date formats are converted into one datetime format.
5. Processed datasets are saved separately from raw datasets.
6. Large datasets are kept outside GitHub, while code and documents are stored in the repository.
7. Any new assumptions will be added to this file if they are needed later in the project.
